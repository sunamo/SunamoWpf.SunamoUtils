# SunamoWpf.SunamoUtils

## Short description

NuGet balíček pomocných tříd vrstvy _sunamo vyčleněných z SunamoWpf (ABT, BTS, CA, CAG, CharHelper, ClipboardHelper, ControlNameGenerator aj.). Využívá TextCopy, ObjectDumper.NET a Microsoft.Windows.Compatibility. Součást sbírky wnp.
